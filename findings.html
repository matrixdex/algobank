Findings

Every finding is reported. None is suppressed because it is common or probably harmless.

high: a file that runs on every Python start (.pth, sitecustomize.py); a new power (network, process, environment, native code, TOP) and where it enters; new eval, exec or deserialization; a native binary (native binary detected. not checked); a new dependency; an sdist, whose build code is not analyzed; a known malicious or vulnerable release. The exit status is 1.

warning: a called package that was not algobanked in the same run. The exit status does not change.

medium, low, info: other new dynamic code, new entry points, changed dependency ranges, data files, and the scope each function uses.
