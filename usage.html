Usage

Algobank has no network access and writes no files. It reads only the wheels you give it. Your package manager downloads them.

Installation

pip install algobank

standard library only, no dependencies

Download packages

pip download --only-binary :all: -d wheels/ requests==2.34.2

This command downloads the package and every package it calls. pip has the network. Algobank does not. The option --only-binary :all: downloads wheels only. So pip never runs the build code of an sdist.

Find package scope with algobank scope

algobank scope wheels/*.whl
pip install --no-index --find-links wheels/ requests==2.34.2

algobank scope gives one report per file. A called package that is missing from wheels/ gets a warning. The second command installs exactly the files that algobank checked.

Compare 2 versions with algobank diff

pip download --no-deps --only-binary :all: -d wheels/ requests==2.31.0
pip download --no-deps --only-binary :all: -d wheels/ requests==2.32.3
algobank diff wheels/requests-2.31.0-py3-none-any.whl wheels/requests-2.32.3-py3-none-any.whl

Save report

algobank diff wheels/requests-2.31.0-py3-none-any.whl wheels/requests-2.32.3-py3-none-any.whl > report.txt
algobank diff --json wheels/requests-2.31.0-py3-none-any.whl wheels/requests-2.32.3-py3-none-any.whl > report.json

Your shell writes the file. Algobank only prints.

Recommended report export

old=wheels/requests-2.31.0-py3-none-any.whl
new=wheels/requests-2.32.3-py3-none-any.whl
o=$(basename "$old"); n=$(basename "$new"); v1=${o#*-}; v2=${n#*-}
name=${o%%-*}-${v1%%-*}-${v2%%-*}
algobank diff "$old" "$new" > "$name.txt"
algobank diff --json "$old" "$new" > "$name.json"

The file name is package-oldversion-newversion, for example requests-2.31.0-2.32.3. The script takes these fields from the wheel names. No name or version in a wheel name contains a hyphen. So the file name splits back into 3 fields on the hyphen.

Options

algobank scope wheels/*.whl --json
algobank scope wheels/*.whl --ignore-native

--json gives the same report for programs and agents. --ignore-native reports native binaries but does not fail on them.

Exit status: 0 means no high finding. 1 means a high finding. 2 means an error.
