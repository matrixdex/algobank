Usage

Algobank has no network access and writes no files. It reads only the wheels you give it. Your package manager downloads them.

# INSTALL
pip install algobank                     # standard library only, no dependencies

# DOWNLOAD (pip has the network, algobank does not)
pip download --only-binary :all: -d wheels/ requests==2.34.2    # the package and every package it calls
                                         # --only-binary: never run an sdist's build code

# CHECK EVERY FILE
algobank scope wheels/*.whl              # one report per file; called packages missing from wheels/ get a warning

# INSTALL EXACTLY WHAT WAS CHECKED
pip install --no-index --find-links wheels/ requests==2.34.2

# COMPARE TWO VERSIONS
pip download --no-deps --only-binary :all: -d wheels/ requests==2.31.0
pip download --no-deps --only-binary :all: -d wheels/ requests==2.32.3
algobank diff wheels/requests-2.31.0-py3-none-any.whl wheels/requests-2.32.3-py3-none-any.whl
