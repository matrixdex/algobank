algobank Algorithm Bank

  • Algobank gives each function in a package (Python) a content hash. Hashes form a code Merkle tree, whose top hash is the code root.
  • Algobank shows what each part of a package can reach: file, network, process, env, native and TOP. Package scope is the union of all package part scopes.
  • TOP means: Algobank cannot see what this code does. It could do anything.
  • Algobank has no network access, writes no code, writes no files and only reads input files and its own advisory data, without execution. No build scripts.
  • It uses the Python standard library only. No dependencies.
