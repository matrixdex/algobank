Algobank (Algorithm Bank for composable secure algorithms and software insurance)

Architecture (Architecture reference)

Bank (Algobanked versions, by hash. A version stays admitted until it is deemed insecure.)

Findings (Every finding is reported. None is suppressed because it is common or probably harmless.)

Known Exploits and Vulnerabilities (Algobank ships the published advisories for the 1,000 most downloaded PyPI packages: malicious releases from OpenSSF (MAL-) and known vulnerabilities from PyPA (PYSEC-), unchanged, in known.json.)

Source (github.com/matrixdex/algobank: the library on main, this website on web.)

Usage (Algobank has no network access and writes no files. It reads only the wheels you give it. Your package manager downloads them.)

Vision (Algobank is the bank of algorithms where codegens securely run the work of other codegens, vetted by codegens.)
